# API配置管理器 (API Config Manager)

一个强大的SillyTavern扩展，用于保存和管理多个API配置，支持一键快速切换。

## ✨ 功能特性

- 🔧 **多配置管理**: 保存无限个API配置（URL、密钥、首选模型）
- 🪟 **弹窗管理**: 连接面板顶部一键打开，列表独立滚动，告别整页下滑
- 🎨 **三种美化**: 白色、黑色，以及可选的“跟随酒馆 CSS”，自动记住选择
- 📱 **双端居中**: 电脑、手机及横屏居中显示，按可见区域调整弹窗，底部操作不随表单滚走
- 🔎 **快速搜索**: 按名称、分组、模型或来源筛选，保留紧凑配置卡片
- 📌 **配置置顶**: 常用 API 跨分组优先显示，支持取消置顶，刷新或编辑后保留设置
- ⚡ **一键切换**: 快速应用任意配置并自动连接
- 🔌 **单条 / 全部连接**: 获取端点模型列表并显示连通结果，不发送测试消息或生成请求，不切换当前 API
- 🤖 **智能模型选择**: 自动获取和选择API支持的模型
- 🧩 **多个首选模型**: 每条配置保存多个模型，点击卡片展开后可逐个应用或删除，记住默认模型，兼容旧配置
- 🔄 **自动重连**: 应用配置后自动重新连接API
- 🔒 **凭据隔离**: 配置保存在酒馆用户设置中；连接仅使用该配置的端点和凭据，不借用其他配置的密钥

## 🚀 快速安装

### 方法1：通过Git URL安装（推荐）
1. 打开SillyTavern
2. 进入 **扩展设置** 页面
3. 找到 **"Install Extension"** 或 **"安装扩展"**
4. 输入以下Git URL：
```
https://github.com/Lorenzzz-Elio/api-config-manager.git
```
5. 点击安装，重启SillyTavern

### 方法2：手动安装
1. 下载本仓库的所有文件
2. 将文件夹放置到 `SillyTavern/public/scripts/extensions/third-party/api-config-manager/`
3. 重启SillyTavern
4. 在扩展设置中启用"API Config Manager"

## 📖 使用指南

### 打开管理弹窗
1. 在 Chat Completions 的 API 连接面板顶部点击 **“API配置管理器”整条显示栏**（或右侧打开图标）；连接面板不存在时，入口会放在扩展设置中。
2. 默认打开 **“已保存”** 列表，可在顶部搜索框输入关键词，多个关键词用空格分隔。
3. 列表只在弹窗内滚动，搜索栏始终可见；点击 **“新增配置”** 或某条配置的 **“编辑”**，切换到独立表单。
4. 点击右上角 **×**、弹窗外的遮罩或按 **Esc** 关闭。关闭后再次打开会保留当前页面、搜索条件和未保存的输入（刷新页面不保留草稿）。

### 选择美化样式
点击弹窗顶部、全部连接旁边的美化图标，在三种模式之间循环切换：

- **太阳 · 白色美化**：独立的浅色配色。
- **月亮 · 黑色美化**：独立的深色配色。
- **颜料盘 · 跟随酒馆 CSS**：第三种美化，沿用酒馆主题变量，以及 `.popup`、`.menu_button`、`.text_pole` 的自定义外观；更改酒馆主题或这些通用 CSS 规则后，打开的弹窗会即时更新。

选择会保存在扩展设置中，关闭、重新打开或刷新后继续使用；首次使用默认为白色。切换美化不会清空搜索、修改已保存的 API 配置或丢弃表单草稿，也不会改动酒馆本身的主题或自定义 CSS。黑白模式保持独立配色，不会因为酒馆换主题而自动改色。

第三种模式跟随全局主题与通用控件样式；只针对聊天区或特定侧边栏节点的 CSS 不会自动作用于弹窗。需要单独调整时，可在酒馆自定义 CSS 中使用 `#api-config-modal[data-api-config-theme="tavern"]` 限定范围，例如：

```css
#api-config-modal[data-api-config-theme="tavern"] {
    --api-config-width: 840px;  /* 最大宽度，窄屏仍会自动收缩 */
    --api-config-height: 700px; /* 最大高度，优先适应可见区域 */
}
```

手机上打开弹窗、切换页面不会主动唤起软键盘；点击输入框后，弹窗按可见区域重新居中，表单单独滚动。美化使用紧凑的单图标控件，小屏幕上卡片操作保持独立一排，并适当增加触控高度。

### 保存API配置
1. 点击配置管理器显示栏打开弹窗，再选择“新增配置”
2. 填写配置信息：
   - **配置名称**: 如"OpenAI GPT-4"、"Claude API"、"本地Ollama"等
   - **API URL**: 如"https://api.openai.com/v1"
   - **API密钥**: 您的API密钥（可选）；输入框右侧的小眼睛可显示 / 隐藏，反代密码 / Token 也支持。默认隐藏，离开编辑页、切换配置/来源或关闭弹窗后会重新隐藏，不清空草稿。
   - **首选模型**: 可选，可保存多个。逐个输入模型 ID 后按回车或点击 **＋** 添加；重复模型自动去重。点击已添加模型旁的 **星标** 设置默认模型，点击 **×** 从草稿移除。
3. 点击“获取模型”可获取 API 支持的模型列表；从列表中每选择一次就添加一个模型，可连续选择多个。保存时，输入框里尚未点击添加的最后一个模型也会一并保存。
   - 获取时只使用当前表单凭据或此配置已绑定的同来源密钥，不遍历、写入或轮换酒馆活动密钥。Google 直连需填写 Key 或使用此配置的已有绑定，不借用其他配置的 Key。
   - 最多等待 **20 秒**，超时会弹窗提示并恢复按钮；获取中再次点击可取消。修改端点/凭据或离开编辑页会停止等待，旧结果不会覆盖新配置。已转发的后台请求可能仍会完成。接口没有模型列表时仍可手动添加。
4. 点击底部固定的“保存配置”，保存成功后自动回到列表；“取消”会清空未保存的输入并返回列表

### 使用已保存的配置
1. 打开弹窗，在“已保存”列表中找到要使用的配置（可搜索名称、分组、模型或来源）
2. 点击"应用"按钮
3. 扩展将自动：
   - 设置API URL和密钥
   - 重新连接到API
   - 选择该配置的默认模型（如果设置了）

### 展开和切换首选模型
- 点击配置卡片的信息区或空白处展开/收起已保存的模型；保存多个模型时，配置名称前会显示展开箭头。键盘聚焦卡片信息区后也可按 **Enter / 空格** 切换。
- 展开后，每个模型都有独立的 **应用 / 删除** 按钮。点击“应用”会切换到这个配置和模型，并把它记为默认模型；之后点击卡片主“应用”按钮，也会使用它。
- 删除模型只影响这一条模型，不删除配置、密钥或其他模型；删除默认模型时改用剩余的第一个，删除最后一个后配置仍保留为“未设置模型”。
- 搜索会匹配全部已保存的模型，不限于默认模型。置顶、搜索或切换列表不会把模型操作对应到其他配置。
- 旧版的单个首选模型自动兼容，不需要重新录入。编辑和取消只修改草稿，保存后才更新配置。

### 置顶常用 API
- 点击配置旁的 **图钉按钮** 置顶，再点一次 **取消置顶**。电脑上可悬停查看按钮说明。
- 置顶配置集中显示在列表最前面的 **“置顶”** 区，保持原保存顺序，不重复显示；原分组会显示在来源标签中。
- 取消置顶后回到原分组，保留该分组原来的折叠状态。置顶区始终展开，不受同名分组影响。
- 支持置顶多条配置；搜索仍只显示匹配项。设置随配置保存，关闭、刷新、编辑或同名覆盖后不会丢失。
- 置顶不应用配置、不发起连接，也不会中断正在进行的连接或清空编辑草稿。手机端图钉放在信息右侧，原有四个操作按钮保持独立一排。

### 连接端点（不发送测试消息）
- 每条配置都有 **“连接”** 按钮；状态显示在模型信息旁边，包括未连接、连接中、已连通、未连通或超时。悬停状态文字可看本次耗时、模型数量或失败说明。
- 顶部 **“全部连接”** 会处理所有已保存配置，包含搜索隐藏、折叠的项目；每次最多并行 3 条，单条最多等待 20 秒，底部显示进度与结果统计。
- 进行中按钮变为 **“停止连接”**：取消后续排队并停止等待已发出的请求。已经由酒馆后台转发的模型列表请求可能仍会完成。
- 与酒馆 Custom / Google AI Studio 原生连接一样，只经 `/api/backends/chat-completions/status` 获取模型列表；**不是“测试消息”，不调用聊天或生成接口**。连接需要访问端点，并不是完全不联网。
- **“连接”与“应用”是两回事**：连接不改动当前 API、模型、活动密钥或编辑草稿；只有“应用”才切换正在使用的配置。缺少地址或凭据时会提示补全，不会借用其他配置的密钥；无密钥的 Custom 配置按匿名端点处理。
- 结果只保留在本次页面会话，关闭弹窗后重新打开仍可查看，刷新后重置；关闭弹窗不会自动重连，也不会停止已主动发起的批量任务。
- “已连通”仅说明本次模型列表请求成功，不保证模型生成权限、余额或具体模型可用。不支持模型列表接口的端点可能显示未连通，扩展不会改用生成请求来验证。
- 已移除扩展内部的更新按钮、版本联网检查和自动更新提示；不会在加载后自行检查更新。

### 管理配置
- **置顶**: 点击图钉把常用配置放到列表前面，再点一次恢复原分组
- **编辑**: 点击"编辑"按钮修改配置
- **删除**: 点击"删除"按钮移除不需要的配置
- **应用**: 点击"应用"按钮快速切换到该配置
- **连接**: 只查看该配置的端点连通情况，不改变当前正在使用的配置
- **分组**: 点击分组标题折叠或展开；搜索期间临时展开命中的分组，不改变已保存的折叠状态
- **键盘**: Tab 在弹窗内切换焦点；页面选项卡支持左右方向键；Esc 关闭弹窗

## 🔒 隐私与安全

### 存储与请求范围
- 配置经酒馆的 `extension_settings` 保存到酒馆用户设置，并不只存在浏览器中；设置导出和备份可能包含密钥，请勿公开分享。
- 连接所需的端点与凭据会交给您使用的酒馆服务器，由它向所配置的服务转发模型列表请求；不发送给扩展作者。
- 单条/全部连接不发送聊天内容，不保存连接结果，也不写入或轮换活动密钥。
- ✅ 扩展代码开源，可自由审查

详细隐私说明请查看 [PRIVACY.md](PRIVACY.md)

## 技术说明

### 支持的API字段
- **Custom API URL**: `#custom_api_url_text`
- **Custom API Key**: `#api_key_custom` (通过secrets系统)
- **Custom Model**: `#custom_model_id` 和 `#model_custom_select`

### 自动化功能
- **自动连接**: 应用配置后自动触发 `$('#api_button_openai').trigger('click')`
- **模型选择**: 如果指定了首选模型，会自动设置到相应字段
- **智能匹配**: 优先从模型列表中选择，如果不存在则手动设置模型ID

### 数据存储
配置数据存储在SillyTavern的`extension_settings`中，格式如下：
```json
{
  "api-config-manager": {
    "configs": [
      {
        "name": "配置名称",
        "url": "API URL",
        "key": "API密钥"
      }
    ]
  }
}
```
